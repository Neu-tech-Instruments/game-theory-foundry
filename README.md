# Neural Architect Workstation: The Early Warning Radar

**The One-Sentence Pitch:**
A smart early-warning radar for small businesses that predicts when critical materials are going to get expensive or run out.

### **How It Works**

1. **The Material Tree:** Generates dynamic "family trees" for products (e.g., a "Veranda"), showing all required materials (wood, aluminum, screws) in a "living" factory view.
2. **Global Surveillance:** Secretly monitors global data feeds—news, shipping routes, and Polymarket prediction odds—while the user sleeps.
3. **The Early Warning System:** Replaces boring spreadsheets with a high-fidelity dashboard. Flashes warnings for shortages or price spikes *before* they happen.
4. **The "I Told You So" Timeline:** Tracks predictions against actual price movements to prove exactly how much capital was protected.

### **The "Secret Sauce"**
Unlike standard software, this workstation uses a **Contrarian Game-Theory Engine**. It predicts "competitor panic" and hoarding behavior, allowing users to move *before* the market reacts.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
